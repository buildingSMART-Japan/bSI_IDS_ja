# IDSの文書化
- [UserManualには](UserManual/)、IDSの内容や使い方の説明が書かれています。まずは[README](UserManual/README.md)ファイルをご覧ください。
- [例には](Examples/)、いくつかのサンプル.idsファイルが含まれています。
