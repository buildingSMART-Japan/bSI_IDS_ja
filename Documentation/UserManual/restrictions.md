# 複雑な制限
**ファセット・パラメータを**指定する場合、**単純値**または**複合制限を**指定できます。**単純な値は**、テキスト、数値、またはブーリアン（TRUE / FALSE）です。一方、**複雑な制限は**、有効な値のピック・リスト、命名規則、数値範囲などを表すことができます。制限は、4つの異なる方法で指定することができます：

- 列挙
- パターン
- 限度
- 長さ

## 列挙
**Enumeration**制限とは、値が許容される値のリストの1つでなければならないことを意味します。例えば、材料が"コンクリートか 鋼鉄の"どちらかであることを指定することができます。

数値はリストとして指定することもできる。例えば、コンクリート強度等級を "25"、"30"、"35"、40 のいずれかに指定することができる。ユーザーが 30 を選択した場合は、**Enumerationに**従います。しかし、ユーザーが 31 を選択した場合、それは適合しません。

"TRUEや" FALSEの"ように、ブール値を指定することもできる。しかし、ブール値の性質上、ユーザーは常に"TRUE"か"FALSE の"どちらかを選択しなければならないので、列挙型としてブール値を指定することは一般的に無意味である。

許容値のリストを指定しても、ユーザーはそのリストから1つの値しか選択できないことに注意してください。

## パターン
**パターン**制限は、命名規則または命名スキームを表します。例えば、ドア・タイプに DT01、DT02、DT03 などの命名規則を使用するよう指定する場合、DT という"文字を最初に付け、その後に 2 つの数字を付けるというパターンを作成することができます。

コンピュータには、**正規表現と**呼ばれるテキストのパターンを定義する特別な方法がある。特殊な記号を使い、コンピュータに数字や文字、あるいは任意の文字を指定します。ワイルドカードとして`*` 文字を使ったコンピュータのパターンには、すでにお馴染みかもしれない。たとえば、`DT*` というパターンは、`DTA` 、`DTB` 、あるいは`DT01` という値でも満たすことができる、と言うことができます。**Regexは**少し複雑ですが、その代わり、パターン内のルールをより具体的にすることができます。AEC業界における命名規則の重要性を考えると、**Regexの**学習に投資することを強くお勧めします。

**Regexは**確立された手法であり、非常に高度なパターン・マッチを実現できるが、その機能を完全に習得するには時間がかかる。そのため、ここではいくつかの基本的な例のみを示す。すべての機能を教えることは IDS のドキュメントの範囲外です。IDSをフルに活用するには、オンラインのチュートリアルやリソースがたくさんあります：

- [初心者向け正規表現チュートリアル](https://regexone.com/)
- [オンライン正規表現テストサイト](https://regex101.com/)
- [XML正規表現](https://www.regular-expressions.info/xml.html)

Regex には複数の"フレーバー"または"方言が"あるため、最初の 2 つのリンクは有用な学習リソースですが、IDS で使用できない Regex 機能も含まれている可能性があることに注意してください。3番目のリンク（XML正規表現）は、IDSで使用できるものについての権威あるソースとして参照できます。一般的に、IDS の Regex はシンプルで、高度な Regex 機能は含まれていません。

## 限度
**Bounds**制限では、値が数値であり、値の範囲内に収まっていなければならないことを指定できます。最小値、最大値、またはその両方を指定することができます。また、最小値と最大値のどちらを含めるかを指定することもできます（例：`>=` と `<=`） or exclusive (e.g. `>`や`<` のように)。例えば、値が"3以上 10以下"でなければならないと指定することができます。

## 長さ
**長さの**制限は、値で許可される正確な文字数を指定します。例えば、長さを3と指定した場合、`ABC` や`123` のような3文字の値は要件を満たします。`AB` や`ABC123` のような他の値は、要件を満たしません。

同様に、**最大長（Max Length**）と**最小長（Min Length**）を指定することもできる。**最大長を**5にすると、`ABCDE` の値は許可されますが、`ABCDEF` のような値は許可されません。**最小長を**3にすると、`ABC` の値は許可されますが、`AB` の値は許可されません。

`.{3}` のような**パターンを**指定することでも同じ効果を得ることができるが、**長さ**制限の方が単純で計算が速いことに注意。
