# マテリアルファセット

IFCの壁、ドア、窓などの要素には**素材**最も単純なケースでは、1つの要素に1つの**素材**例えば、椅子は "木 "の素材から作られているかもしれない。**マテリアルファセット**を持つ要素をフィルタリングしたり、要求したり、禁止したりできます。**素材**.

原価計算、スケジューリング、持続可能性、構造解析など、多くの分野は正しいかどうかにかかっている。**素材**関連性と正確なスペル。

## パラメータ

| パラメータ | 必須 | 制限あり | 意味 |
| --------- | -------- | -------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **価値** | ❌ | ✔️ | 任意のマテリアル名またはカテゴリー。 マテリアル名は通常、プロジェクトまたは地域の慣習に固有のものです。 要素は、指定された名前またはカテゴリーを持つ**マテリアル**で作られていなければなりません。 複数の**マテリアル**がある場合、その名前またはカテゴリーを持つ**マテリアル**、**レイヤー**、**プロファイル**、**コンポジション**も要件を満たします。 |
| **ユーアールアイ** | ❌ | ❌ | 材料の統一資源識別子（Uniform Resource Identifier）。解釈の一貫性を確保するために、材料の標準化された定義を参照するために使用されます。 ターゲット資源は、名前と定義を含み、ISO 12006-3およびISO 23386に準拠することが望ましいです。 これは、IDSチェックの対象とならないオプション属性です。IFCモデルは、同じURIまたは任意のURIを持つ必要はありません。有効なURIの1つのソースは、[bSDD](https://search.bsdd.buildingsmart.org/)であり、URIの例は、"合板 "のものです：[https://identifier.buildingsmart.org/uri/cei-bois.org/wood/1.0.0/class/8dca70a2-01a2-489b-9381-fbeff09db8dc](https://identifier.buildingsmart.org/uri/cei-bois.org/wood/1.0.0/class/8dca70a2-01a2-489b-9381-fbeff09db8dc)。 |
|  |  |  |  |

\* The material Category is an optional attribute of [IfcMaterial](https://ifc43-docs.standards.buildingsmart.org/IFC/RELEASE/IFC4x3/HTML/lexical/IfcMaterial.htm), and is recommended by the IFC to be one of 'concrete', 'steel', 'aluminium', 'block', 'brick', 'stone', 'wood', 'glass', 'gypsum', 'plastic', or 'earth'.

について`value`フィールドはオプションである。 オプション属性`uri`は単なるメタデータであり、IDSのチェック対象ではない。

パラメータが指定されていない場合は、すべての**素材**名前やカテゴリーに関係なく、存在しなければならない。

## IFCマテリアルリレーションズ

要素は複数の**材料**3つのシナリオが考えられる：

- **レイヤー素材**要素（例えば壁やスラブ）は、厚さを持つ材料層（例えばスタッド層、断熱層、石膏層）でパラメトリックに定義される。 各層は、それぞれ異なる**素材**.
- **プロファイルされた素材**柱や梁などの要素は、経路に沿って押し出されるプロファイル（Cプロファイル、Zプロファイル、Iプロファイルなど）でパラメトリックに定義されます。 複合柱や複合梁は、複数の異なるプロファイルを持つことがあります。**材料**.
- **構成材料**要素（窓やスラブなど）の一部が、異なる材料でできているもの。**材料**(例：窓ガラスと窓枠）または混合（例：コンクリートスラブは、セメント、骨材などの割合で構成される）。

![マテリアルファセット](Graphics/material-facet.png)

IFC（4x3以前）の素材([Ifcマテリアル](https://ifc43-docs.standards.buildingsmart.org/IFC/RELEASE/IFC4x3/HTML/lexical/IfcMaterial.htm))をオブジェクト([IfcObject](https://ifc43-docs.standards.buildingsmart.org/IFC/RELEASE/IFC4x3/HTML/lexical/IfcObject.htm))を通して[IfcRelAssociates資料](https://ifc43-docs.standards.buildingsmart.org/IFC/RELEASE/IFC4x3/HTML/lexical/IfcRelAssociatesMaterial.htm)の関係にある。 

しかし、その関係は必ずしも直接的なものばかりではない。 オブジェクトがタイプによって定義されていたり、より大きなアセンブリの中に集約されたパーツであったりすることもある。 また、例えばレイヤーのセットや構成要素のリストなど、素材とオブジェクトを関連付ける方法は複数ある。

![素材との関係](Graphics/material-relation.svg)

IDSは、ユーザーにとって材料関係を単純化し、材料の関連付けを単純に指定できるようにし、様々な可能性のある関係の解釈をIFC-IDSのチェックツールに移行します。

## マテリアルファセット解釈

### 適用性

| 素材価値 | IDSの解釈 |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| - | 関連するマテリアルを持つすべてのエンティティに適用される。 マテリアルの関係を持っている場合、物理的なオブジェクトだけをフィルタリングする良い方法。 |
| スチール | Steel*（正確な綴りと大文字小文字）という名前の関連材料を持つすべてのエンティティに適用されます。 エンティティがより多くの材料関連を持っている場合は関係ありません。 |

### Requirements

| IDSカーディナリティ | 素材価値 | コンフィギュレーションを許可しますか？ | IDSの解釈 |
| --------------- | -------------- | ---------------------- | ------------------------------------------------------------------------------------------------ |
| 必須 | - | ✅ | 適用可能なオブジェクトは、その名前に関係なく、少なくとも1つの関連素材を持っていなければならない。 |
| 必須 | スチール | ✅ | 適用されるオブジェクトは、*Steel*という素材に関連したものでなければなりません。 その他の素材も可能です。 |
| オプション | - | ❌ | マテリアルの有無を指定することに付加価値はない。 |
| オプション | スチール | ✅ | 適用されるオブジェクトは素材を持つ必要はないが、もし持つのであれば、その中に*スチール*が含まれていなければならない。 |
| 禁止 | - | ✅ | 適用されるオブジェクトは、いかなる素材も関連付けられてはならない。 |
| 禁止 | スチール | ✅ | 該当するオブジェクトに関連する素材の中に、スチール*があってはならない。 |
