# アトリビュート・ファセット

IFCモデルの各エンティティには、標準化された**属性**.**属性**は、すべてのIFCエンティティに関連する限られた基本データのセット（通常は10未満）です。 これらはIFC標準によって固定されており、カスタマイズすることはできません。

以下は、一般的な属性とその意味である：

- **グローバルID**要素の一意な識別子。
- **名称**もし図面やスケジュール表に注釈を入れる必要がある場合は*名称*例えば、ポンプ*名称*P-10-Aかもしれない。
- **説明**通常、名称の長い形であり、説明的で人間にとって読みやすいように書かれる。 例えば、ポンプは*説明*かもしれない*吸水ポンプ*.
- **タグ**通常、短いコードまたは番号で、別のBIMアプリケーションまたは製品仕様にリンクすることがある。

## Attribute facet interpretation

### 適用性

| 属性名 | 属性値 | IDSの解釈 |
| -------------- | --------------- | ------------------------------------------------------------------------------- |
| 説明 | - | Description*が入力されているすべてのエンティティに適用されます（Nullまたは欠損ではありません）。 |
| 説明 | 回答 | Description*が値*Answer*を持つすべてのエンティティに適用される。 |

### Requirements

| IDSカーディナリティ | 属性名 | 属性値 | コンフィギュレーションを許可しますか？ | IDSの解釈 |
| --------------- | -------------- | --------------- | ---------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| 必須 | 説明 | - | ✅ | 該当するオブジェクトは、*Description*属性が設定されていなければならない（すなわち、NULLではない）。 |
| 必須 | 説明 | 回答 | ✅ | 属性*Description*は値*Answer*を持たなければならない（該当するオブジェクトで）。 |
| オプション | 説明 | - | ❌ | オプションは意味をなさない。 |
| オプション | 説明 | 回答 | ✅ | 該当するオブジェクトに属性*Description*が存在する場合、それは値*Answer*を持つ必要がある。 |
| 禁止 | 説明 | - | ✅ | 属性*Description*は、たとえ空であっても、該当するオブジェクトに存在してはならない。 |
| 禁止 | 説明 | 回答 | ✅ | 属性*Example*は、値*Answer*を持ってはならない（該当するオブジェクトで）。 この場合、Nullも許容される値である。 |
