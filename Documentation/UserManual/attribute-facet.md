# アトリビュート・ファセット
IFC モデルの各エンティティは、標準化された**属性（Attributes）の**リストを持っている。**属性は**、すべてのIFC エンティティに関連する基本的なデータの限られたセット（通常は 10 未満）である。これらはIFC 標準によって固定されており、カスタマイズすることはできない。

以下は、一般的な属性とその意味である：

- **GlobalId**：要素の一意な識別子
- **名前（Name**）：人間のために対象物を識別するための短い名前またはラベル。図面やスケジュールに注釈を入れる場合、*Nameが*よく使われる。例えば、ポンプの*名称は*P-10-Aとなる。
- **説明**："有益なコメントを交換するために提供される"。通常、名称の長い形式で、説明的で人間にとって読みやすいように書かれる。例えば、ポンプの*Descriptionは* *Water Suction Pump(吸水ポンプ*)である。
- **タグ**："シリアル番号やポジション番号など、製品の特定のインスタンスにおける識別子。発生レベルでの識別子である。"通常は短いコードまたは番号で、別のBIMアプリケーションまたは製品仕様にリンクすることがある。

IFC エンティティの定義にとって重要でない情報は、**Attribute ではなく** **Property** として保存されます。詳細については、[**プロパティ・ファセットの**](property-facet.md)ドキュメントを参照してください。

このため、**属性は**、特定の要素への**適用可能性を**指定したり、特定の要素を特定の方法で識別、命名、または記述しなければならないという**要件を**指定したりするのに適した方法である。

IFC クラスで利用可能な**Attributes**と、その潜在的な値を確認するには、IFC のドキュメントをチェックする必要があります。スキーマで有効な**Attribute**のリストを見つける方法を以下に示します。 IFC4X3_ADD2スキーマで有効な Attribute のリストを見つける方法を示します。この手順は、すべてのIFC バージョンで同様です。

 1. 指定するIFC クラスのドキュメント・ページを参照する。例えば、[ IfcWall のドキュメント・ページです](http://ifc43-docs.standards.buildingsmart.org/IFC/RELEASE/IFC4x3/HTML/lexical/IfcWall.htm)。

 1. ドキュメントの**属性**セクションまでスクロールダウンしてください。デフォルトでは、すべての属性が表示されていないことに注意してください。すべての属性を表示するには、"*非表示の継承属性を表示するを*"クリックします。IFC4 の場合、"*Attribute inheritance*"text headerをクリックすると、すべての属性の表が表示されます。

 1. **属性**表には、**各属性の** **名前が**表示される。横に数字がなく、イタリック体である**属性は**指定できないことに注意。列挙された**属性のみが**指定可能である。例えば、IfcWall に対して**Name**属性を指定することはできるが、**ConnectedTo を**指定することはできない。

ドキュメントをチェックする代わりに、IDSオーサリングソフトウェアを使えば、有効な**「属性（Attribute）」を**絞り込むことができる。

## パラメータ
| <nobr>パラメータ</nobr>     | <nobr>必須</nobr>       | <nobr>制限</nobr>あり         | <nobr>意味</nobr> |
| --------- | -------- | -------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **名称**　　　　　 | ✔️　　　　　 | ✔️　　　　　 | IFC スキーマの有効な属性名。 |
| **価値** | ❌ | ✔️ | 属性のデータ型に適した任意の値。詳細は[DataTypeのドキュメントを](../ImplementersDocumentation/DataTypes.md#xml-base-types)参照。 |

## アトリビュート・ファセットの解釈
### 適用性
| <nobr>属性</nobr>名       | <nobr>属性</nobr>値       | IDSの<nobr>解釈</nobr>         |
| -------------- | --------------- | ------------------------------------------------------------------------------- |
| 説明　　　　　 | -　　　　　　 | *説明（Description）が*入力されている（Nullや欠損でない）すべてのエンティティに適用されます。 |
| 説明 | 回答 | *Description*が値*Answer* を持つすべてのエンティティに適用される。 |

### 必要条件
| IDS<nobr>カーディナリティ</nobr> | <nobr>属性</nobr>名       | <nobr>属性</nobr>値       | <nobr>コンフィギュレーションを</nobr>許可しますか？ | IDSの<nobr>解釈</nobr>         |
| --------------- | -------------- | --------------- | ---------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| 必須　　　　　 | 説明　　　　　 | -　　　　　　 | ✅　　　　　　 | 該当するオブジェクトは、*Description*属性が設定されていなければならない（すなわち、NULLであってはならない）。 |
| 必須 | 説明 | 回答 | ✅ | 属性*Descriptionは*値*Answerを*持たなければならない（該当するオブジェクトで）。 |
| オプション | 説明 | - | ❌ | オプションは意味をなさない。 |
| オプション | 説明 | 回答 | ✅ | 該当するオブジェクトに属性*Descriptionが*存在する場合、その値は*Answer*である必要があります。 |
| 禁止 | 説明 | - | ✅ | 属性*Descriptionは*、たとえ空であっても、該当するオブジェクトに存在してはならない。 |
| 禁止 | 説明 | 回答 | ✅ | 属性*Exampleは*（該当するオブジェクトで）値*Answerを持っては*ならない。この場合、Nullも許容値です。 |
