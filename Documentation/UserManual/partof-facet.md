# パートオブファセット
このファセットは、一部のオブジェクトを識別するか（適用性）、あるいは、一部のオブジェクトを要求する（要件）。

IFCのオブジェクトは、他のオブジェクトと複数の関係を持つことができます。IDS part-ofは、以下のタイプを再帰的にナビゲートして、エンティティが他のオブジェクトの一部であるかどうかを判断します：

- **IFCRELAGGREGATES**リレーションシップは、複数の小さなサブオブジェクトを1つの大きなオブジェクトに集約する方法を説明します。例えば、多くの建物の階は建物を構成します。あるいは、多くの梁、床板、接合部がスラブを構成する。あるいは、多くのブラケット、マリオン、鋼板がアセンブリを構成する。
- **IFCRELASSIGNSTOGROUP**関係は、複数のオブジェクトをどのようなユースケースでオブジェクトの集合体にグループ化できるかを説明します。例えば、ダクト、AHU、ファン、ルーバーはすべて1つの配電システムにグループ化することができます。あるいは、ケーブル、分電盤、GPOを1つの回路にグループ化することもできる。あるいは、スペースはゾーンにグループ化され、保守可能な資産はインベントリーにグループ化される。
- **IFCRELCONTAINEDINSPATIALSTRUCTURE**リレーションシップは、複数のオブジェクトを特定の場所に配置する方法を説明します。例えば、ポンプがスペースにあったり、柱がレベル2の建物の階にあったり、ストリートファニチャーが建物の敷地にあったりします。すべてのオブジェクトは、IFC で単一のプライマリ・ロケーション・コンテナを持つ必要があります。この関係は、プライマリ・ロケーション・コンテナのみを対象とします。
- **IFCRELNESTS の**関係は、物理オブジェクトがより大きなホストオブジェクトに接続される方法を説明するもので、通常はあらかじめ開けられた穴や接続端子などの物理的な接続を介して接続されます。ホストが移動すると、接続されたネストされたオブジェクトも一緒に移動します。
- **IFCRELVOIDSELEMENTIFCRELFILLSELEMENT**関係は、要素が開口部を通して他の要素とどのように関係するかを記述します。

`relation`パラメータが指定されていない場合、含む実体を識別するために、6つすべてを(再帰的に)考慮する。そうでない場合は、指定された関係タイプだけを(同じく再帰的に)考慮する。

## パラメータ
| パラメータ | 必須 | タイプ | 意味 |
| ------------ | -------- | --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **エンティティ** | ✔️ | エンティティ・ファセット | XML 内にネストされた有効な IDS`entityType`"（IFCSYSTEM" など）。大きなオブジェクトのIFCクラスが、必要な実体と一致する。大文字で表します。 |
| **関係** | ❌ | ストリング | 上記の 6 つのサポートされる型から選択された 1 つの関係。省略された場合は、直接または間接的に、そして推移的に(再帰的に)評価されなければならない有効なIFC関係構造がすべて評価され、指定された場合は、指定された型のみが(再帰的に)評価されなければならない。大文字で表現します。 |
                                                                                                                                                                                                       

## 一部の'ファセット解釈
### 適用性
| PartOf エンティティ | PartOf関係* | IDSの解釈 |
| ------------- | --------------------------------- | ----------------------------------------------------- |
| IFCSPACE | - | *IfcSpace の*一部のすべてのオブジェクトに適用されます。 |
| IFCSPACE | IFCRELCONTAINEDINSPATIALSTRUCTURE | *IfcRelContainedInSpatialStructure*関係で定義されている、*IfcSpace* に含まれるすべてのオブジェクトに適用されます。 |

### 必要条件
| IDSカーディナリティ | PartOf エンティティ | PartOf関係* | コンフィギュレーションを許可しますか？ | IDSの解釈 |
| --------------- | ------------- | --------------------------------- | ---------------------- | ----------------------------------------------------------------------------------------------------------- |
| 必須 | IFC_PH_0_C379ED7 | - | ✅ | 適用可能なオブジェクトは、*IfcSpace*エンティティとの関係を持っている必要があります（有効な関係をすべてたどる）。 |
| 必須 | IFCSPACE | IFCRELCONTAINEDINSPATIALSTRUCTURE | ✅ | 適用可能なオブジェクトは、*IfcRelContainedInSpatialStructure*と*IfcSpace*エンティティの関係を持っている必要があります。 |
| オプション | IFCSPACE | - | ❌ | 許されない。一部の部品になるかどうかを指定することに付加価値はない。 |
| オプション | IFCSPACE | IFCRELCONTAINEDINSPATIALSTRUCTURE | ❌ | 許されない。一部の部品になるかどうかを指定することに付加価値はない。 |
| 禁止 | IFCSPACE | - | ✅ | 適用可能なオブジェクトは、*IfcSpace*に関連するものであってはなりません。 |
| 禁止 | IFCSPACE | IFCRELCONTAINEDINSPATIALSTRUCTURE | ✅ | 適用可能なオブジェクトは、*IfcRelContainedInSpatialStructure*と*IfcSpace の*関連を持ってはなりません。 |

\* フィールドは XML 属性です。


## 例
| 適用意図 | 要件意図 | ファセットの定義 |
| ---------------------------------------------------------------- | ------------------------------------------------------------ | --------------------------------------------------------------- |
| カーテン・ウォールを直接構成するあらゆる実体 | 実体（マリオンなど）はカーテンウォールの一部でなければならない。 | "Relation=IFCRELAGGREGATES", "Entity=IFCCURTAINWALL" |
| カーテンウォールの直接的または間接的な一部の事業体 | 実体（マリオンなど）はカーテンウォールの一部でなければならない。 | "Entity=IFCCURTAINWALL" |
| 流通システムの一部の事業体 | 実体（ダクトなど）が配電システムの一部であること。 | "Relation=IFCRELASSIGNSTOGROUP", "Entity=IFCDISTRIBUTIONSYSTEM" |
| 空間に存在するあらゆる実体 | エンティティ（ポンプなど）は、スペースに配置されていなければならない。 | "Relation=IFCRELCONTAINEDINSPATIALSTRUCTURE", "Entity=IFCSPACE" |
| ウォールによってホストされるすべてのエンティティ | エンティティ（窓など）は壁に固定されていなければならない。 | "Relation=IFCRELNESTS", "Entity=IFCWALL" |
