# パートオブファセット
このファセットは、一部のオブジェクトを識別するか（適用性）、あるいは、一部のオブジェクトを要求する（要件）。

IFC のオブジェクトは、他のオブジェクトと複数の関係を持つことができます。IDS part-of は、以下の型を再帰的にナビゲートして、エンティティが他のオブジェクトの part-of であるかどうかを判断します：

- **IFCRELAGGREGATES**関係は、複数の小さなサブオブジェクトを1つの大きなオブジェクトに集約する方法を説明します。例えば、多くの建物の階は建物を構成する。あるいは、多くの梁、床板、ジョイントがスラブを構成する。あるいは、多くのブラケット、マリオン、鋼板がアセンブリを構成する。
- **IFCRELASSIGNSTOGROUP の**関係では、複数のオブジェクトをどのようなユースケースでオブジェクトの集合体にグループ化できるかを説明します。例えば、ダクト、AHU、ファン、ルーバーはすべて1つの配電システムにグループ化することができる。あるいは、ケーブル、分電盤、GPOを1つの回路にグループ化することもできる。あるいは、スペースはゾーンにグループ化され、保守可能な資産はインベントリーにグループ化される。
- **IFCRELCONTAINEDINSPATIALSTRUCTURE の**リレーションシップは、複数のオブジェクトを特定の場所に配置する方法を説明します。例えば、ポンプがスペースにあったり、柱がレベル2の建物の階にあったり、ストリートファニチャーが建物の敷地にあったりします。すべてのオブジェクトは、IFCに1つのプライマリ・ロケーション・コンテナを持つ必要があります。このリケーションの対象は、主要なロケーションコンテナのみです。
- **IFCRELNESTS**関係は、物理オブジェクトがより大きなホストオブジェクトに接続される方法を説明するもので、通常はあらかじめ開けられた穴や接続端子などの物理的な接続を介して接続されます。ホストが移動すると、接続されたネストされたオブジェクトも一緒に移動します。
- **IFCRELVOIDSELEMENT**関係は、空隙がどのように要素に属するかを説明します。
- **IFCRELFILLSELEMENT**関係は、要素がどのように空隙を埋め、空隙の一部になるかを説明します。

`relation`パラメータが指定されていない場合、含む実体を識別するために6つすべてを（再帰的に）考慮する。

## パラメータ
| <nobr>パラメータ</nobr> | <nobr>必須</nobr> | <nobr>タイプ</nobr> | <nobr>意味</nobr> |
| ------------ | -------- | --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **エンティティ**　　　　 | ✔️　　　　　 | エンティティ・ファセット | XML 内にネストされた有効な IDS`entityType`"（IFCSYSTEM" など）。大きなオブジェクトの IFC クラスが、必要な実体と一致する。大文字で表します。 |
| **関係** | ❌ | ストリング | 上記の 6 つのサポートされるタイプから選択された 1 つのリレーションシップ。省略された場合は、直接または間接的に、そして推移的に（再帰的に）評価されなければならない有効な IFC の関係構造が評価されます。大文字で表現する。 |
                                                                                                                                                                                                       

## Part Of'ファセットの解釈
### 適用性
| <nobr>PartOf</nobr>エンティティ | PartOf<nobr>関係*。</nobr> | IDSの<nobr>解釈</nobr> |
| ------------- | --------------------------------- | ----------------------------------------------------- |
| IFCSPACE | -　　　　　　 | *IfcSpace* の一部であるすべてのオブジェクトに適用されます。 |
| IFCSPACE | IFCRELCONTAINEDINSPATIALSTRUCTURE | *IfcRelContainedInSpatialStructure*関係で定義されている、*IfcSpace* 内に含まれるすべてのオブジェクトに適用されます。 |

### 必要条件
| IDS<nobr>カーディナリティ</nobr> | <nobr>PartOf</nobr>エンティティ | PartOf<nobr>関係*。</nobr> | <nobr>コンフィギュレーションを</nobr>許可しますか？ | IDSの<nobr>解釈</nobr> |
| --------------- | ------------- | --------------------------------- | ---------------------- | ----------------------------------------------------------------------------------------------------------- |
| 必須　　　　　 | IFCSPACE | -　　　　　　 | ✅　　　　　　 | 適用可能なオブジェクトは、*IfcSpace*エンティティとの関係を持っている必要があります（有効な関係をすべてたどる）。 |
| 必須 | IFCSPACE | IFCRELCONTAINEDINSPATIALSTRUCTURE | ✅ | 適用可能なオブジェクトは、*IfcRelContainedInSpatialStructure*と*IfcSpace*エンティティの関係を持たなければなりません。 |
| オプション | IFCSPACE | - | ❌ | 許されない。部品になるかどうかを指定することに付加価値はない。 |
| オプション | IFCSPACE | IFCRELCONTAINEDINSPATIALSTRUCTURE | ❌ | 許されない。部品になるかどうかを指定することに付加価値はない。 |
| 禁止 | IFCSPACE | - | ✅ | 該当するオブジェクトは、*IfcSpace*に関連付けられていてはいけません。 |
| 禁止 | IFCSPACE | IFCRELCONTAINEDINSPATIALSTRUCTURE | ✅ | 該当するオブジェクトは、*IfcRelContainedInSpatialStructure*と*IfcSpace が*関連付けられていてはいけません。 |

\* フィールドは XML 属性です。

## 例
| <nobr>適用</nobr>意図          | <nobr>要件</nobr>意図        | ファセットの<nobr>定義</nobr>   |
| ---------------------------------------------------------------- | ------------------------------------------------------------ | --------------------------------------------------------------- |
| カーテン・ウォールを直接構成するあらゆる実体 | 実体（マリオンなど）はカーテンウォールの一部でなければならない。 | "Relation=IFCRELAGGREGATES", "Entity=IFCCURTAINWALL" |
| カーテンウォールの直接的または間接的な一部の事業体 | 実体（マリオンなど）はカーテンウォールの一部でなければならない。 | "Entity=IFCCURTAINWALL" |
| 流通システムの一部の事業体 | 実体（ダクトなど）が配電システムの一部であること。 | "Relation=IFCRELASSIGNSTOGROUP", "Entity=IFCDISTRIBUTIONSYSTEM" |
| 空間に存在するあらゆる実体 | エンティティ（ポンプなど）は、スペースに配置されていなければならない。 | "Relation=IFCRELCONTAINEDINSPATIALSTRUCTURE", "Entity=IFCSPACE" |
| ウォールによってホストされるすべてのエンティティ | エンティティ（窓など）は壁に固定されていなければならない。 | "Relation=IFCRELNESTS", "Entity=IFCWALL" |
