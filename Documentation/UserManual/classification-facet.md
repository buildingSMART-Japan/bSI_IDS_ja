# クラシフィケーションファセット
**分類システムは**、要素を分類するために定義された階層です。一般的な分類システムには、"Uniclass 2015"、"ETIM"、CCIなどがあります。**システム**内には、以下のような、要素をより特定性の高いレベルに分類する短い参照**コードの**階層があります。 "EF_25_10"そして "EF_25_10_25".IFC モデル内のどのオブジェクトも、[分類参照を](https://ifc43-docs.standards.buildingsmart.org/IFC/RELEASE/IFC4x3/HTML/lexical/IfcClassificationReference.htm)持つことができます。

**クラシフィケーション・ファセットは**、**エンティティ・ファセットとは**異なります。**クラシフィケーション・ファセットは**、組み込みの IFC クラスと定義済みタイプに限定されます。これとは対照的に、分類とは、サード・パーティの、IFC以外の分類を指します。

IFC モデルでは、分類名、日付、バージョン、およびその他のデータを追跡して、それらを一意に識別します。このため、**クラシフィケーション**要件は、**プロパティ・ファセットではなく**、**クラシフィケーション・ファセットを**使用する必要があります。

**分類は**、**適用可能な**エンティティを特定したり、資産管理システム、作業内訳構造、または調整要件などのワークフローによって、エンティティが指名された**分類**システムに従う必要があることを**要求**したりするのに最適な方法です。

## パラメータ
| <nobr>パラメータ</nobr>     | <nobr>必須</nobr>       | <nobr>制限</nobr>あり         | <nobr>意味</nobr> |
| ---------- | -------- | -------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **システム**　　　　 | ✔️　　　　　 | ✔️　　　　　 | 分類システムの名前。 |
| **価値** | ❌ | ✔️ | 分類システム内の参照コードの値。通常、正式名称またはショートコードである。 |
| **URI** | ❌ | ❌ | クラスの統一資源識別子。解釈の一貫性を確保するために、クラスの標準化された定義を参照するために使用される。対象となるリソースは、名前と定義を含み、ISO 12006-3 と ISO 23386 に準拠することが望ましい。IFC モデルが同じ URI を持つ必要はありません。有効なURIのソースの1つは[bSDD](https://search.bsdd.buildingsmart.org/)であり、URIの例としては"Beam: [https://identifier.buildingsmart.org/uri/buildingsmart/ifc/4.3/class/IfcBeam。](https://identifier.buildingsmart.org/uri/buildingsmart/ifc/4.3/class/IfcBeam) |

### 適用性
| <nobr>分類</nobr>システム         | <nobr>分類</nobr>価値           | IDSの<nobr>解釈</nobr>         |
| --------------------- | -------------------- | --------------------------------------------------------------------------------------------------- |
| ETIM　　　 | -　　　　　　 | 値に関係なく、*ETIM*分類システムを用いて分類されたすべてのエンティティに適用される。 |
| ETIM | EC000009 | 分類システム*ETIMの*コード*EC000009を*持つすべての事業体に適用される。 |
