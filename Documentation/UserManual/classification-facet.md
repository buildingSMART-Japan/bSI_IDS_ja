# クラシフィケーションファセット
**分類システムは**、要素を分類するために定義された階層です。一般的な分類システムには、"Uniclass 2015"、"ETIM"、"CCIなどが"あります。**システム**内には、"EF_25_10"や"EF_25_10_25 のように、要素をより詳細なレベルに分類する短い参照**コードの**階層があります。IFCモデルのどのオブジェクトも、[分類参照を](https://ifc43-docs.standards.buildingsmart.org/IFC/RELEASE/IFC4x3/HTML/lexical/IfcClassificationReference.htm)持つことができます。

**クラシフィケーション・ファセットは**、**エンティティ・ファセットとは**異なります。**クラシフィケーション・ファセットは**、組み込みのIFCクラスと定義済みのタイプに限定されています。これとは対照的に、分類はサード・パーティの非IFC 分類を指します。

IFCモデルでは、分類名、日付、バージョン、および分類を一意に識別するためのその他のデータが記録されます。このため、**クラシフィケーション**要件は、**プロパティ・ファセットではなく**、**クラシフィケーション・ファセットを**使用する必要があります。

**分類は**、**適用可能な**エンティティを特定したり、資産管理システム、作業内訳構造、または調整要件などのワークフローによって、エンティティが指名された**分類**システムに従う必要があることを**要求**したりするのに最適な方法です。

## パラメータ
| パラメータ | 必須 | 制限あり | 意味 |
| ---------- | -------- | -------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **システム** | ✔️ | ✔️ | 分類システムの名前。 |
| **価値** | ❌ | ✔️ | 分類システム内の参照コードの値。通常、正式名称またはショートコードである。 |
| **URI** | ❌ | ❌ | クラスの統一資源識別子。解釈の一貫性を確保するために、クラスの標準化された定義を参照するために使用される。ターゲットリソースは名前と定義を含み、ISO 12006-3 と ISO 23386 に準拠することが望ましい。これは IDS チェック対象外のオプション属性であり、IFCモデルが同じ URI または任意の URI を持つ必要はありません。有効なURIの1つのソースは[bSDDで](https://search.bsdd.buildingsmart.org/)、URIの例は"Beam: https:[//identifier.buildingsmart.org/uri/buildingsmart/ifc/4.3/class/IfcBeam。](https://identifier.buildingsmart.org/uri/buildingsmart/ifc/4.3/class/IfcBeam) |


## クラシフィケーション・ファセットの解釈
### 適用性
| 分類システム | 分類価値 | IDSの解釈 |
| --------------------- | -------------------- | --------------------------------------------------------------------------------------------------- |
| ETIM | - | 値に関係なく、*ETIM*分類システムを用いて分類されたすべてのエンティティに適用される。 |
| ETIM | EC000009 | 分類システム*ETIMの*コード*EC000009を*持つすべての事業体に適用される。 |
