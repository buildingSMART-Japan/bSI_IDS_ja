# クラシフィケーションファセット

A**分類システム**は、要素を分類するために定義された階層です。 一般的な分類システムには、"Uniclass 2015"、"ETIM"、"CCI "などがあります。**システム**短いリファレンスの階層がある**コード**IFCモデル内のどのオブジェクトも、"EF_25_10 "や "EF_25_10_25 "のように、要素をより詳細なレベルで分類することができます。[分類リファレンス](https://ifc43-docs.standards.buildingsmart.org/IFC/RELEASE/IFC4x3/HTML/lexical/IfcClassificationReference.htm).

について**クラシフィケーションファセット**とは異なる。**エンティティ・ファセット**...」と言った。**エンティティ・ファセット**のメソッドとしても機能する。**分類**これに対して分類とは、IFC以外の第三者の分類を指す。

IFCモデルは、分類名、日付、バージョン、その他のデータを記録し、それらを一意に識別します。 このため、IFCモデルは、分類名、日付、バージョン、その他のデータを記録し、それらを一意に識別します、**分類**を使用する必要があります。**クラシフィケーションファセット**とは対照的である。**プロパティファセット**.

**分類**を識別するための素晴らしい方法である。**適用可能**または**必要**事業体は指名された**分類**資産管理システム、作業内訳構造、調整要件などのワークフローによるシステム。

## パラメータ

| パラメータ | 必須 | 制限あり | 意味 |
| ---------- | -------- | -------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **システム** | ✔️ | ✔️ | 分類システムの名前。 |
| **価値** | ❌ | ✔️ | その分類システム内での参照コードの値。 通常は正式名称か短いコードである。 |
| **ユーアールアイ** | ❌ | ❌ | クラスの統一資源識別子（Uniform Resource Identifier）。解釈の一貫性を確保するために、クラスの標準化された定義を参照するために使用されます。 ターゲット資源は、名前と定義を含み、ISO 12006-3およびISO 23386に準拠することが望ましいです。 これは、IDSチェックの対象とならないオプション属性です。IFCモデルは、同じURIまたは任意のURIを持つ必要はありません。有効なURIの1つのソースは、[bSDD](https://search.bsdd.buildingsmart.org/)であり、URIの例は、"Beam "のものです：[https://identifier.buildingsmart.org/uri/buildingsmart/ifc/4.3/class/IfcBeam](https://identifier.buildingsmart.org/uri/buildingsmart/ifc/4.3/class/IfcBeam)。 |

## Classification facet interpretation

### 適用性

| 分類システム | 分類 価値 | IDSの解釈 |
| --------------------- | -------------------- | --------------------------------------------------------------------------------------------------- |
| エティム | - | 値に関係なく、*ETIM*分類システムを使って分類されたすべてのエンティティに適用される。 |
| エティム | EC000009 | 分類システム*ETIM*のコード*EC000009*を持つすべての事業体に適用される。 |
