# クラシフィケーションファセット
**分類システムは**、要素を分類するために定義された階層です。一般的な分類システムには、"Uniclass 2015"、"ETIM"、CCIなどが"あります。**システム**内には、以下のような、要素をより特定性の高いレベルに分類する短い参照**コードの**階層があります。 EF_25_10"そして "EF_25_10_25".IFC モデル内のどのオブジェクトも、[分類参照を](https://ifc43-docs.standards.buildingsmart.org/IFC/RELEASE/IFC4x3/HTML/lexical/IfcClassificationReference.htm)持つことができます。

**クラシフィケーション・ファセットは**、**エンティティ・ファセットとは**異なります。**クラシフィケーション・ファセットは**、組み込みのIFC クラスと定義済みのタイプに限定されます。これに対して、Classification は、IFC 以外のサード・パーティの分類を指します。

IFC モデルは、分類名、日付、バージョン、および分類を一意に識別するためのその他のデータを追跡します。このため、**クラシフィケーション**要件は、**プロパティ・ファセットではなく**、**クラシフィケーション・ファセットを**使用する必要があります。

**分類は**、**適用可能な**エンティティを特定したり、資産管理システム、作業内訳構造、または調整要件などのワークフローによって、エンティティが指名された**分類**システムに従う必要があることを**要求**したりするのに最適な方法です。

## パラメータ
| <nobr>パラメータ</nobr>     | <nobr>必須</nobr>       | <nobr>制限</nobr>あり         | <nobr>意味</nobr> |
| ---------- | -------- | -------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **システム**　　　 | ✔️　　　　　 | ✔️　　　　　 | 分類システムの名前。 |
| **価値** | ❌ | ✔️ | 分類システム内の参照コードの値。通常、正式名称またはショートコードである。 |
| **Uri** | ❌ | ❌ | クラスの統一資源識別子。解釈の一貫性を確保するために、クラスの標準化された定義を参照するために使用される。対象となるリソースは名前と定義を含み、ISO 12006-3 と ISO 23386 に準拠することが望ましい。これは、IDS のチェックの対象とならないオプションの属性である。IFC モデルは、同じ Uri または任意の Uri を持つ必要はない。有効なURIのソースの一つは[bSDD](https://search.bsdd.buildingsmart.org/)であり、URIの例は"Beamの"ものである[。https://identifier.buildingsmart.org/uri/buildingsmart/ifc/4.3/class/IfcBeam 。](https://identifier.buildingsmart.org/uri/buildingsmart/ifc/4.3/class/IfcBeam) |
